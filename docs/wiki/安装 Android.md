# 安装 · Android(手机 / 电视)

测试版:手机上已经真机跑通(连接、分流、断开、升级),电视端目前只在模拟器上验证过,欢迎反馈。

## 装

侧载 `godusevpn-<版本>-android-<ABI>.apk`。手机与电视基本都是 **arm64**,不确定就装 universal 包。
首次安装要允许「未知来源」。**最低 Android 8.0**。

## 和别的端有什么不同

- **同一套界面与功能**:守护进程(设置、多订阅与刷新回退链、规则组、状态机、定时测速)和页面与 Windows / Linux 是同一份代码,数据布局也一样(`settings.json`、`profiles/`、`config.json`、`logs/`),只是放在应用私有目录。
- **隧道**:第一次点「连接」会弹系统的 VPN 授权;之后 VpnService 按引擎给的参数建隧道(地址、路由、DNS、按应用直连),通知栏常驻状态并带「断开」。应用自身**不**排除在隧道之外 —— 排除了的话本应用套接字的回包会从物理网卡漏走,表现为 DNS 通、TCP 全断(真机实测)。
  所以连上之后,订阅刷新、升级下载、补规则集这些走的都是隧道。
- **按应用直连**:Windows 的「按进程直连」在这里就是应用包名(设置 → 分流),这些应用整个绕过 VPN。
- **开机自启**:引擎按上次状态自动连;Android 12 起后台起前台服务受限,开机与升级完成的广播窗口里会先把服务拉起来。系统设置里也可以把它设为「始终开启的 VPN」。
- **没有「停用网卡 IPv6」这个开关**:应用没有权限改物理网卡的 IPv6 配置。那一端只有「把 v6 接进 VPN 再拒绝」这一层,设置页因此不显示这一项。详见 [[关于 IPv6]]。

## 电视

同一个包在 Android TV / 盒子上以**横屏**显示,遥控器方向键移动焦点,能走完全部操作。
订阅链接建议用剪贴板粘贴(在手机上复制,再用输入法或投屏工具送过去)。

### 老电视的浏览器内核

界面是装在系统 WebView 里的网页。**国行电视(小米、创维、海信这些)不走 Google 认证,系统自带的 WebView
往往停在很旧的版本且不会更新** —— 比如小米电视 EA70 停在 Chrome 66 一线。页面里只要有一处它不认识的新语法,
整份脚本就会在解析阶段失败,屏幕上是一片白,什么提示都没有。

所以页面这一套**只用 Chrome 66 认识的写法**,仓库里有 `web/compat_test.go` 盯着,越线 CI 直接不过。

万一还是白屏:现在页面自带兜底,它会把出错原因直接打在屏幕上(深色底白字,带设备的 UserAgent)。
**把那一屏拍下来**就能定位。壳这边也会把内核版本和页面报的错写进 logcat(标签 `godusevpn`),
「日志 → 导出诊断包」里能带出来。

## 升级

「关于 → 检查更新」:下载对应 ABI 的 APK、校验 SHA256 后拉起系统安装器;装完引擎按上次状态重新连接。
**每一版都用同一把签名密钥**,否则系统不让覆盖安装。

## 诊断

「日志 → 导出诊断包」,经系统分享发出去。
