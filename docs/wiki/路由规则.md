# 路由规则

<img src="https://raw.githubusercontent.com/Maoyangui/godusevpn/master/docs/screenshots/rules.png" width="260" align="right" alt="路由规则页">

规则**只在「规则」模式下生效**。全局和直连模式是两条独立分支,不看这里。

<br clear="all">

## 默认规则(内置)

三条,自上而下:

| 分支 | 默认 | 可改成 |
|---|---|---|
| 局域网与私网地址 | 直连 | 直连 / 代理 / 拒绝 |
| 国内域名与 IP | 直连 | 直连 / 代理 / 拒绝 |
| 其余流量 | 代理 | 代理 / 直连 |

改乱了点「还原默认」一步回出厂。

国内域名与 IP 用的是 sing-box 官方的 `geosite-cn` / `geoip-cn` 规则集,经代理更新;本地目录下有同名 `.srs` 就用本地文件。

## 自定义规则组

每组要填三样:

| 字段 | 说明 |
|---|---|
| **名称** | 自己看的,比如「流媒体」 |
| **出口** | 代理(当前节点)/ 直连 / 拒绝 / 自动选择 / 某个具体节点 |
| **条件** | 任意多条,**任一命中即算命中** |

条件类型:

| 类型 | 例子 |
|---|---|
| 域名后缀 | `netflix.com` |
| 完整域名 | `www.example.com` |
| 域名关键词 | `google` |
| 域名正则 | `^cdn[0-9]+` |
| IP 段 | `1.2.3.0/24` 或单个 IP |
| 端口 | `443` 或 `6000-7000` |
| 进程名 | `steam.exe`(Android 上是应用包名) |
| geosite 类别 | `netflix`、`google`、`openai` |
| geoip 国家 | `us`、`jp` |

一次可以粘贴多个值,用逗号或空格分隔,回车添加。

## 匹配顺序

```
用户规则组(自上而下,可拖动排序)
        ↓ 都没命中
默认规则:局域网 → 国内 → 其余
```

规则组可以**启停**(开关不删),可以**排序**、编辑、删除。

出口选了某个具体节点,而这个节点不在当前订阅里时,回落到「代理」。

## 别的分流入口

这几项不在规则页,在设置 → 分流:

- **按进程 / 应用直连**:每行一个 exe 名(Android 上是包名),这些程序整个不走代理。
- **广告拦截**:开了之后按内置规则集拒绝广告域名。
- **局域网直通**:私网段不进 TUN(默认开)。

网关模式下还有按设备的策略,见 [[网关模式]]。

## 底下是怎么落地的

每个规则组渲染成一条 sing-box 路由规则(多种条件用 `logical/or` 组合),放在 `clash_mode` 分支之后、内置国内直连之前。

改规则会重新生成配置并让内核热更新;**只有改到 TUN 这类入站参数才会重启内核**。
