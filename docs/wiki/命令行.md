# 命令行

Windows 上是两个程序:`godusevpn-svc`(服务)与 `godusevpn-cli`(操作),要**以管理员身份**跑。
Linux 与 macOS 上是同一个 `godusevpn` 二进制,子命令一样,要 root。

## 常用

```
godusevpn-svc install                          注册服务并启动
godusevpn-svc uninstall                        停服务并撤销注册

godusevpn-cli profile https://面板/sub/用户名    设置订阅(自动补 format=json)
godusevpn-cli connect                          连接
godusevpn-cli disconnect                       断开
godusevpn-cli status                           当前状态:连没连、哪个节点、延迟、出口、时长
godusevpn-cli mode global | rule | direct      切模式
godusevpn-cli nodes                            列出节点与延迟
godusevpn-cli select <节点名>                   选节点(auto = 自动选择)
godusevpn-cli test                             测全部节点
godusevpn-cli rules                            列出规则组
godusevpn-cli settings <键>=<值> ...            改设置,见 设置项与文件位置
godusevpn-cli logs 200 core                    看最近 200 行日志(core = 内核那一路)
godusevpn-cli diag                             导出诊断包(订阅地址已打码)
```

## Linux 专有

```
godusevpn passwd                               改面板密码
godusevpn devices                              网关模式:列出局域网设备
godusevpn device <MAC> <follow|proxy|direct|reject> [名字]
godusevpn install | start | stop | status | uninstall
```

## 排障时最有用的三条

```bash
godusevpn-cli status      # 先看它到底在哪一步
godusevpn-cli logs 200 core   # 内核说了什么
godusevpn-cli diag        # 要发给别人看就导这个
```

`config.json` 就在数据目录里(见 [[设置项与文件位置]]),想知道规则最终渲染成什么样直接看它。
