# 日常使用

界面四端是同一套,下面说的每一处在哪一端都一样。

## 第一次打开

先填面板给的**订阅链接**才能进入;没有订阅的话点「或手动添加节点」。之后在侧边菜单的「订阅管理」里可以加更多条,点一下切换。

## 首页

<img src="https://raw.githubusercontent.com/Maoyangui/godusevpn/master/docs/screenshots/home.png" width="260" align="right" alt="首页">

从上往下:

- **大圆环**:点一下连接 / 断开。圆环转起来是正在连,亮起来是连上了,变红是出错(下面会写原因)。
- **大字时长**:连上之后走的连接时长;没连上时这儿显示状态(未连接 / 连接中 / 出错原因)。
- **出口卡片**:地区旗帜 + 当前节点 + 这条线路**真正的出口地址与城市** + 延迟。点一下直接换节点。
- **速度卡片**:实时上下行、本次连接累计流量,底下是最近一分钟的曲线。
- **三个格子**:模式、订阅、节点,点开各是一个面板。
- **有新版本时**:顶栏「佛跳墙」旁边亮一个红色 **NEW**(客户端每小时自己查一次),点它直接到「关于」升级;侧栏里「关于」那一项也带 NEW。

### 出口那一行是怎么来的

**经当前节点**去查的,不是节点名上写的机房位置 —— 节点自己再套一层的话,真正的出口就不在那儿了。

先问 `ipwho.is`(免密钥,一次 JSON 给地址 / 国家 / 一级行政区 / 城市 / 运营商),不通就退回 Cloudflare 自家的 `cdn-cgi/trace`(只给地址与国家代码,但几乎不会连不上)。两个都不通就显示「正在查出口」,不影响使用。

什么时候重测:**连上时、换节点时、自动选择在后台切了节点时**,此外每 10 分钟复查一次。

> 这两个端点回的都是「对方看到的你是谁」,不需要再拿这个 IP 去别处查一次归属地;请求走隧道,对方看到的是节点的出口地址,不是你本机的。不想让第三方看到这次查询,到设置 → 隐私关掉「查询出口地址」,首页就不再显示出口。

## 三种模式

| 模式 | 行为 |
|---|---|
| 规则 | 国内域名与 IP 直连,其余走代理。默认的三条分支自己可以改,见 [[路由规则]] |
| 全局 | 全部流量走代理 |
| 直连 | 全部流量直连,隧道还在但不转发 |

切模式靠内核的 Clash API,**毫秒级,不重启内核**。首页下方和侧边菜单的状态卡里都能切。

> 直连模式下首页不显示出口地址 —— 那时候流量根本不经节点,挂着节点的地址是误导。

## 选节点

点首页的出口卡片或「节点」格子。

- **打开时测一次速,之后不再定时测**。只有选了「自动选择」才会按设置里的周期(默认 3 分钟)测全部节点并切到最快的那个。
- 顶上按地区归堆成一排标签,点一下只看该地区;标签自动换行,不用横向滚。
- 名字里写了倍率(`2x` / `x2` / `0.5倍`)会单独标出来。
- 延迟条越长表示越快;`不通` 表示这个节点测不通。
- **换节点会掐断旧连接**,不然已经建好的长连接会继续用老节点。

## 订阅

「订阅管理」里可以加 / 改 / 删 / 刷新多条订阅,点整行切换当前用哪条。

刷新有**回退链**:经当前节点刷新失败就改用自动选择组,再不行直连刷新。回退只作用于订阅刷新这一条请求,选中的节点和其它流量的路由都不受影响。

订阅面板里还会显示用量与到期(面板给的话)。

面板在落地页设置了「选购 / 续费」地址的话,每条订阅上会多一颗**续费**按钮,点一下用系统浏览器打开——代理自己填了地址就用代理的,没填用主面板的。快到期(七天内)或流量用掉九成时按钮转橙色,并写明还剩几天;已经到期的写「已到期」。到期之后订阅拉不到了,按钮也还在——面板会把地址随那个 404 一起给,第一次添加就已到期的订阅也会在错误旁边给一颗续费按钮。面板没设置就不显示这颗按钮。

在「自动选择」和手动指定节点之间来回切也是就地换的,不重连。刷新**不会断开**正在用的连接:增删的节点立刻出现在节点列表里,不用点什么"应用"。刚加进来的节点(内核还没有)或参数改了的节点,你选中它时会重建配置重连一次。只有你正在用的那个节点被面板删掉、或者参数改了,才会自动重连——留着也是连不上的。

## 手动添加节点

没有订阅,或者想单独加几个节点时用。入口在「添加订阅」下面的「或手动添加节点」。

- **贴分享链接**:vless、vmess、trojan、ss、hysteria2、tuic、anytls、socks、http 都认,也认 base64 编码的一整段和 sing-box 的节点 JSON。贴一条就填到下面的表单里,核对后保存;贴多条就列出来,整批添加,解析不了的行会写明第几行。
- **逐项填写**:选好协议,表单只显示这个协议要填的项,不常用的(ALPN、指纹、混淆密码、端口跳跃、拥塞控制等)收在「更多选项」里。
- 保存前内核先干跑一遍,填错的不会存进去。内容完全相同的节点不会重复添加。

这些节点归在一条叫「手动节点」的项目里,和订阅并列:点「使用」切过去之后,节点列表、测速、规则的用法都一样。它不会刷新,没有用量和到期。「管理节点」里可以改、删、再加;删到一个不剩,这一项也随之移除。节点和订阅缓存一样只存在本机。

## 防流量逃逸

设置 → 隐私里的开关,默认开。开关开、模式是全局或规则、你没点断开,就生效(规则模式还要开着 TUN)。只要还连着,该走隧道的流量就不许从本机网络出去 —— 隧道没起来、内核在重启、节点不通、崩了在重试、设备重启,统统只能等,不漏。

**全局模式**:除了隧道自己(节点连接、订阅刷新的回退、解析节点域名的那一次 DNS)、回环、「局域网直通」开着时的局域网(DNS 除外:Windows 与 macOS 上发往任何地址的 DNS 查询只许走隧道,隧道断开的空档里也不许发给路由器;Linux 用策略路由把 DNS 接进隧道,空档里同样被拦,要内核 4.17 起),别的一律拦下。UPnP 发现(SSDP)与 NAT-PMP / PCP 也不放行:程序能靠它们向路由器问到宽带的公网 IPv4,所以连着时局域网投屏、设备自动发现用不了,手动填地址访问照常。

**规则模式**:隧道正常时和平时一样,直连由内核按规则发出,域名、进程、端口规则都管用。隧道异常时规则由防火墙照着执行:

| | 隧道异常时 |
|---|---|
| 直连规则里的 IP 段(默认是局域网和国内 IP) | 照常直连 |
| 规则明确走隧道的 IP 段、端口,以及拒绝的 | 拦下 |
| 没有命中任何直连 IP 段的(默认「其余」) | 拦下,等隧道恢复 |
| 按域名、进程、端口写的直连规则 | 防火墙认不出,拦下,等隧道恢复 |
| DNS(53 端口) | 照常:发给系统配的解析器,不然直连的网站解析不了。只是解析,要走隧道的连接照样拦下。隧道正常时 DNS 全部进隧道,不走这条 |
| 局域网投屏、设备发现、别人连进本机的服务 | 照常 |

要注意的两点:防火墙只认 IP 段,按域名写的走隧道规则万一解析到放行段里的地址(比如想从海外看的国内站),隧道异常的那段时间防火墙分不出来;隧道异常时本机的 DNS 查询是明文发给系统配的解析器的(介意这一点用全局模式,全局模式连 DNS 也拦)。Android 系统不支持按规则放行,规则模式下隧道异常时直连也要等隧道恢复。网关模式下局域网设备同样按这张表走,另外设成直连的设备照常放行,设成走代理或拒绝的设备不看放行段。

闸是持久的:服务被强杀、崩溃、升级都还在,机器重启后开机就先装上(Windows 连开机到防火墙引擎启动之间那几秒也堵着;Linux 早于联网;macOS 由 launchd 开机拉起,不保证早于联网;梅林开机到守护进程起来之间那几秒没有闸),只有点断开、切到直连模式、关掉开关、卸载这四件事会撤,撤完系统防火墙回到原样:闸是单独的一组规则,不碰你自己的防火墙规则,崩溃或被清掉时也只修自己这组。在规则模式下关开关不用重连。服务起不来时机器会一直断网,用托盘菜单或开始菜单的「恢复网络」解除(见 [[排障]])。各平台的做法与边界见 README 的「防流量逃逸」一节。安卓例外:进程被杀 VPN 接口就没了,设置页有入口把佛跳墙设成系统的「始终开启 + 阻止未经 VPN 的连接」。

## 连接 / 日志

- **连接**页列出当前活动连接:目标、走了哪条链路、命中哪条规则、上下行字节、持续时间;可以单条掐断。
<img src="https://raw.githubusercontent.com/Maoyangui/godusevpn/master/docs/screenshots/logs.png" width="260" align="right" alt="日志:内核一栏按去向筛选">

- **日志**页分「服务」与「内核」两路,可以只看错误、暂停、打开目录、复制、导出诊断包(订阅地址、凭据、访问记录已打码)。
- **内核**一栏上面一排按去向筛选:全部 / 走隧道 / 直连 / 拦截 / DNS,后面是条数。每条连接写成「去向 · 节点」标签加「进程 → 域名:端口」,灰字是解析出来的 IP —— 想知道哪个程序在跑流量、走的哪个节点,点「走隧道」一看便知。
- 点一行前面的连接号(`#1234`),只看这一条连接从进来到出去的全部日志;再点一次回到原来的筛选。复制出来的日志是干净的纯文本,不带颜色码。
- 局域网 / 热点上别的设备经这台机器上网的连接,认不出是哪个程序(进程那一栏是空的)。
