# 从源码构建

```bash
git clone https://github.com/Maoyangui/godusevpn
cd godusevpn
```

需要 **Go 1.27+**(版本以 `go.mod` 为准)。

## 构建标签

内嵌 sing-box 需要这几个,少一个都编不出完整功能:

```
with_quic,with_utls,with_clash_api,with_gvisor
```

## 各端

### 守护进程与命令行(全平台)

```bash
go build -tags with_quic,with_utls,with_clash_api,with_gvisor ./cmd/godusevpn-daemon
go build -tags with_quic,with_utls,with_clash_api,with_gvisor ./cmd/godusevpn-cli
```

Linux 与 macOS 上守护进程和命令行是同一个 `godusevpn` 二进制。

### Windows 图形界面

Wails v2,需要 WebView2 SDK:

```powershell
.\build.ps1
```

图标与版本资源由 `go-winres` 从 `winres/*.json` 生成。

### macOS 图形界面

要开 CGO(Wails 要连 WebKit),还得自己补上 Wails 没声明的框架:

```bash
CGO_ENABLED=1 CGO_LDFLAGS="-framework UniformTypeIdentifiers" \
  go build -tags desktop,production,with_quic,with_utls,with_clash_api,with_gvisor ./cmd/godusevpn
```

编好的二进制放进手工拼的 `.app`(模板在 `cmd/godusevpn/build/darwin/Info.plist`,图标用 `sips` + `iconutil` 现生成 icns)。

### Android

```powershell
deploy\android-build.ps1
```

`gomobile bind ./mobile` 出 AAR → Gradle 出 APK。需要 JDK 17 与 Android SDK / NDK。

## 页面

四端共用 `web/dist` 那一份 HTML / JS / CSS,没有构建步骤,改完直接生效:

- Windows / macOS:由 `//go:embed all:dist` 编进二进制。
- Linux:同上,守护进程内置的 HTTP 面板从这里出。
- Android:Gradle 的 `copyWeb` 任务拷进 assets。

## 图标

```bash
go run ./tools/mkicons -logo cmd/godusevpn/build/logo.png -out cmd/godusevpn/build
```

`logo.png` 是透明底的原图;生成的应用图标会垫一块白色圆角底(和安卓的自适应图标一致),托盘图标保持透明。

## 测试

```bash
go test -tags with_quic,with_utls,with_clash_api,with_gvisor ./...
```

含内嵌 sing-box 对生成配置的干跑校验、管道往返、状态机全路径、设置迁移。

真机验收脚本:

| 平台 | 脚本 |
|---|---|
| Windows | `deploy\windows-test.ps1 <订阅地址>` |
| macOS | `sudo sh deploy/macos-test.sh <订阅地址>` |
| Linux | `sh deploy/linux-test.sh <订阅地址>` |
| Android | `deploy/android-emu-test.sh <订阅地址>`(模拟器冒烟) |

## 介绍站

```bash
node site/build.mjs        # 产物在 site/dist
node site/tools/demo-smoke.mjs
```

无依赖,只用 Node 自带的模块。推到 master 后由 `.github/workflows/pages.yml` 自动发布。

## 发版

推一个 `v*` 的 tag,`build.yml` 会编全平台、算 SHA256 并建 Release。**不打 tag 只推 master 的话不会发版**,产物只留在 CI artifacts 里。
