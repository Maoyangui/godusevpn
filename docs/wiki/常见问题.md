# 常见问题

### 和直接用 sing-box / Clash 客户端有什么区别

这个是给 [m-ui](https://github.com/Maoyangui/m-ui) 面板配的客户端:填一条订阅链接就完事,不用自己配 inbound / outbound / route。
底下确实就是 sing-box,内嵌的,不用另外装。

### 要不要管理员权限

要。建 TUN 网卡、改路由表、改网卡的 IPv6 设置都需要。所以隧道跑在一个 root / 管理员身份的**守护进程**里,界面是普通身份,两边用本地管道说话。

### 关掉窗口会断吗

不会。窗口只是界面。要断开:界面里点断开、托盘里点退出,或者 `godusevpn-cli disconnect`。

### 支持哪些协议

订阅里有什么就支持什么 —— 内嵌的是完整的 sing-box,常见的 VLESS / VMess / Trojan / Shadowsocks / Hysteria2 / TUIC / AnyTLS 都在。

### 为什么默认把 IPv6 关了

因为只挡数据包挡不住信息泄漏:运营商发下来的公网 v6 地址就配在网卡上,原生程序读一遍网卡就拿到了。详见 [[关于 IPv6]]。想开回来在设置里关掉那个开关。

### 「自动选择」多久换一次

按设置里的「定时测速(分钟)」,默认 10 分钟经节点真连一轮全部节点,切到最快的(手动选节点、直连模式、没有流量时不测)。在「自动选择」和手动指定节点之间来回切是就地换的,不断线;只有选中的节点内核里还没有(刚刷新加进来)或参数改了,才重建配置重连一次。
**只在选了自动选择时才测** —— 手动选了某个节点的话后台不会一直测速。

### 节点列表打开时会测速,会不会很费流量

一次测速就是对每个节点发一个 204 请求,几百字节。

### 首页显示的出口地址和节点名对不上

正常。节点名写的是机房位置,真正的出口未必在那儿(节点自己再套一层就不是了)。首页那一行是**实测**的,以它为准。

### 支持分应用代理吗

支持。Windows / macOS / Linux 上是按进程名(设置 → 分流),Android 上是按应用包名。这些程序整个绕过代理 —— 只在规则 / 直连模式下;全局模式下「防流量逃逸」开着时不生效,它们也走隧道。

### 一个订阅能在几台设备上用

看面板那边给的设备数,客户端这边不限制。

### 数据存哪儿,卸载会留东西吗

见 [[设置项与文件位置]]。卸载程序不会删设置和日志,要清干净得手动删那个目录。

### 能自己编译吗

能,见 [[从源码构建]]。GPL-3.0。

### 界面能改成英文吗

设置 → 其它 → 语言,中英两种。

### 为什么 Windows 装的时候有安全提示

程序未签名。代码签名证书要花钱,暂时没买。源码和构建流程都是公开的,不放心可以自己编。

## 佛跳墙自己会连哪些地方

没有遥测,不上报任何东西。除了你的节点,程序只会主动连这些:

| 连哪里 | 什么时候 | 对方看到什么 |
|---|---|---|
| 订阅地址 | 添加、刷新订阅 | 连着时经节点;没连接时、或者经节点都失败时才直连。地址是 http 的话内容没有加密,订阅卡片上会标「未加密」 |
| GitHub(查新版本) | 连着时每小时一次,经节点;没连接时不自动查 | 节点的地址。在「关于」里点检查更新时才可能直连 |
| 出口地址查询(ipwho.is,备用 Cloudflare) | 连上、换节点时,经节点 | 节点的地址。设置 → 隐私可以关 |
| 测速地址(gstatic) | 自动选择时定时一轮、当前节点的健康检查,经节点。节点列表的延迟不经节点,直接量到节点的握手(UDP 协议的节点要真连一次);手动选节点时不碰别的节点 | 节点的地址 |
| 规则集 | 缺规则集时补下载,连着时经节点 | 节点的地址 |
| 本地 DNS(默认 223.5.5.5,加密) | 直连的域名、节点自己的域名 | 这台解析器看得到这些域名。介意的话在设置里换成你信任的解析器 |

隧道异常的那段时间(内核重启、服务没起来、开机到连上之前):规则模式下 DNS 查询是明文发给系统配的解析器的,因为直连的网站要靠它解析,连接本身仍然按规则拦。全局模式 + 防流量逃逸连 DNS 也拦。

连着隧道的时候 DNS 全部进隧道,物理网卡上看不到查询。有两个例外都只在 Linux 上、用 systemd-resolved 而且网卡带搜索域时才有:网卡的 DNS 是路由器的话,查不到的域名、短名字会带上搜索域问路由器一次(路由器一般不往外转);关掉防流量逃逸的话,网卡的 DNS 是公网地址时也一样。

诊断包和命令行 `diag` 的输出里,节点地址、规则里的域名、访问记录都打了码,可以放心贴到 Issue 里。

面板(Linux)默认只给本机和局域网打开,要从外面用优先选 SSH 隧道。
