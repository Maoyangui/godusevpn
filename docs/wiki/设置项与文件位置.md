# 设置项与文件位置

## 文件放在哪

| 平台 | 设置与缓存 | 界面偏好 |
|---|---|---|
| Windows | `%ProgramData%\godusevpn\` | `%APPDATA%\godusevpn\ui.json` |
| macOS | `/Library/Application Support/godusevpn/` | `~/Library/Application Support/godusevpn/ui.json` |
| Linux | 设置 `/etc/godusevpn/`,其余 `/var/lib/godusevpn/` | 同目录 |
| Entware(梅林) | `/opt/etc/` 与 `/opt/var/lib/` | 同目录 |
| Android | 应用私有目录 | 同目录 |

目录里有什么:

| 文件 / 目录 | 内容 |
|---|---|
| `settings.json` | 全部设置(下面那张表) |
| `profiles/` | 订阅缓存(拉回来的节点) |
| `config.json` | 渲染出来给 sing-box 的配置,排障时可以直接看(Windows 上要管理员权限,见下) |
| `rulesets/` | geosite / geoip 的 `.srs`,分三层,见下 |
| `logs/` | 服务与内核日志,按天滚动 |

Windows 上这个目录里有节点凭据、订阅地址和面板密码哈希,所以服务**每次启动**都会把它的权限收成
只有 Administrators 与 SYSTEM 能进(会断掉从 `%ProgramData%` 继承下来的「所有用户可读」)。
用非管理员身份跑时收不动,日志里会说一声。

`logs/` 与 `diag/` 单独放开了普通用户只读 —— 界面要靠它们打开日志、把诊断包复制到桌面,
而这两处本来就不含凭据(诊断包里的配置是脱敏过的,订阅地址也打了码)。
**其余部分要自己进去看(比如 `config.json`)或者往 `rulesets/` 里放文件,得用管理员权限**:
资源管理器里第一次打开会弹一次 UAC 提示(点继续就行),或者用「以管理员身份运行」的终端。

### 规则集目录的三层

查找时从上往下取第一个命中的:

| 位置 | 谁写的 | 说明 |
|---|---|---|
| `rulesets/<tag>.srs` | 你自己放的 | 优先级最高,程序从不写这一层 |
| `rulesets/downloaded/<tag>.srs` | 服务补下来的 | 路由规则里用到了内置没带的 geosite / geoip 类别时,连上之后自动下 |
| `rulesets/builtin/<tag>.srs` | 安装包自带 | `geosite-cn`、`geoip-cn`、`geosite-category-ads-all`;每次启动按程序内置的版本对齐 |

**内核启动不联网拿规则集。** 常用的三个随安装包带上,所以默认设置下装完就能连;
本地找不到的规则集会连同用到它的那条规则一起从配置里摘掉(日志里会列出来),
而不是让内核去现下 —— 下不到就整个起不来,那会让一台全新设备永远连不上。
放进来或下下来的 `.srs` 会先整份解析一遍,解不开的当作不存在(我们自己那两层的坏文件会顺手删掉重来)。

## 设置项

界面上「设置」页的每一项,括号里是命令行的键名。

### 连接

| 项 | 默认 | 说明 |
|---|---|---|
| TUN 模式(`tun`) | 开 | 关掉只开混合端口,软件得自己设代理 |
| TUN 协议栈(`tunStack`) | mixed | macOS 上固定 gvisor,别的平台可选 mixed / system / gvisor |
| 严格路由(`strictRoute`) | 开 | 拦掉绕过隧道访问外部时的异常出口,以及朝路由器的 53 端口 |
| 全局禁直连(`noDirect`) | 开 | 全局模式下只要还连着,任何流量都不许绕过隧道直连:隧道没起来、内核在重启、节点不通都只能等,不漏。放行隧道自己、回环,以及「局域网直通」开着时的局域网;Windows 上开热点 / 网络共享时经本机转发的流量同样只许进隧道(「局域网直通」开着时也放行去局域网的)。闸开着时不做直连测速,节点域名的解析走 DoH 不走明文 53。闸不随服务退出而消失,只有断开 / 切模式 / 关开关 / 卸载才撤,撤不成会在状态里标「撤闸失败」;恢复见 [[排障]] |
| 局域网直通(`lanBypass`) | 开 | `10/8`、`172.16/12`、`192.168/16` 不进 TUN |
| 混合端口(`mixedPort`) | 2080 | HTTP 与 SOCKS5 同一个口,只监听 127.0.0.1;0 = 不开。Android / 电视上不生成(流量全走 TUN,没人会连它,而被占用会让内核起不来) |
| 定时测速(分钟)(`probeMinutes`) | 3 | **只在「自动选择」时生效**:每隔这么久测一轮全部节点并切到最快的;改了就地生效,不重连 |
| 订阅自动刷新(小时)(`updateHours`) | 12 | 0 = 不自动刷新 |
| 连接时停用网卡 IPv6(`disableNicIpv6`) | 开 | 见 [[关于 IPv6]];Android 上没有这一项 |

### DNS

| 项 | 默认 | 说明 |
|---|---|---|
| 远程 DNS(`remoteDNS`) | `https://1.1.1.1/dns-query` | 经代理解析 |
| 本地 DNS(`localDNS`) | `https://223.5.5.5/dns-query` | 直连解析,给国内域名与节点域名用。设成 `system` 时走系统解析器,但「全局禁直连」开着的全局模式下节点域名改用 `223.5.5.5` 的 DoH(明文 53 不该在闸开着时发出去),隧道起来前的那次预解析也不做;填的是域名 DoH 时,闸开着解析这个域名本身同样走 `223.5.5.5` 的 DoH |
| fake-ip(`fakeIP`) | 开 | 只分配 IPv4 段(`198.18.0.0/15`) |
| 允许 IPv6(`ipv6`) | 关 | 打开会同时放开 DNS 的 AAAA、v6 fake-ip 与 v6 出站 |

53 端口与 DNS 协议一律劫持进内核。

### 分流

| 项 | 说明 |
|---|---|
| 广告拦截(`adBlock`) | 按内置规则集拒绝广告域名 |
| 按进程直连(`processDirect`) | 每行一个 exe 名;Android 上是应用包名 |
| 自定义规则组 | 见 [[路由规则]] |

### 网络(Linux)

| 项 | 说明 |
|---|---|
| 网络模式(`netMode`) | `local` 本机 / `gateway` 网关,见 [[网关模式]] |
| 劫持局域网 DNS(`dnsHijack`) | 网关模式下把设备发给本机 53 的查询接进内核 |
| 局域网网段(`lanSubnets`) | 逗号分隔,留空自动 |
| 面板监听(`webListen`) | 如 `0.0.0.0:9800`;非本机地址必须先设密码,改后重启服务生效 |

### 其它

| 项 | 默认 | 说明 |
|---|---|---|
| 日志保留(天)(`logDays`) | 7 | 超期的滚动日志与诊断包自动删;0 = 一直保留 |
| 开机自启 | 视平台 | Windows 是安装时勾选 / 设置页开关;Linux 是服务自启 |
| 语言 / 主题 | 跟随系统 | 存在界面偏好文件里,不在 `settings.json` |

## 命令行改设置

```bash
godusevpn-cli settings ipv6=on tunStack=system probeMinutes=5 logDays=14
```

一次可以给多个键。改完立刻生效(需要重启内核的会自动重启)。
