# 安装 · Windows

**系统要求:Windows 10 1809(内部版本 17763)或更高**,x64 与 ARM64 各一个包。
Windows 7 / 8 用不了,也不打算支持:Go 从 1.21 起不再支持它们(内嵌的 sing-box 需要更高的 Go),微软也停了那两个系统的 WebView2。

## 装

到 [Releases](https://github.com/Maoyangui/godusevpn/releases) 下 `godusevpn-<版本>-windows-<架构>-setup.exe`,双击装。

> **程序未签名。** SmartScreen 弹提示时点「更多信息 → 仍要运行」。买代码签名证书这件事暂时没做。

安装包会做四件事:

| 装了什么 | 说明 |
|---|---|
| 后台服务 `godusevpn` | 自动启动;隧道跑在这里 |
| 托盘客户端 | WebView2 窗口 + 托盘图标,登录时自启(安装时可勾) |
| 命令行 `godusevpn-cli` / `godusevpn-svc` | 排障用,见 [[命令行]] |
| `godusevpn://` 协议 | 落地页一键导入订阅;客户端每次启动也会自己确认一遍,老版本升上来不用重装 |

装完第一次打开要先填面板给的订阅链接。

## 平时怎么用

- **关窗口只是收进托盘**,连接不断。托盘的「退出」才会断开连接并停掉后台服务,TUN 网卡随之消失。
- 隧道网卡叫 `godusevpn`,在「网络连接」里看得到。
- 混合端口 `127.0.0.1:2080`(HTTP 与 SOCKS5 同一个口),给那些非要自己设代理的程序用;设成 0 就不开。

## 升级

「关于 → 检查更新 → 升级并重启」。只替换程序,设置与订阅都保留。也可以直接下新的安装包覆盖装。

## 卸载

控制面板里卸载,或者跑安装目录下的 `unins000.exe`。会撤掉服务与协议注册;`%ProgramData%\godusevpn\` 下的设置和日志需要自己删。

## 装完不放心?

跑一遍验收脚本(管理员 PowerShell):

```powershell
deploy\windows-test.ps1 <订阅地址>
```

会依次检查:服务在不在、订阅拉不拉得到、隧道建没建起来、按规则分流对不对、IPv6 是不是真被拦住且没绕过隧道、各功能页面的接口通不通。
