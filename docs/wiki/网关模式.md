# 网关模式(软路由)

本机模式只代理这台机器;网关模式还代理**经它转发的局域网设备**。适合 OpenWrt / iStoreOS 这类软路由。

需要内核带 nftables —— OpenWrt 22.03 起的 fw4 都有。

## 开

设置 → 网络 → 网络模式选「网关」,或者:

```bash
godusevpn settings netMode=gateway
```

然后把局域网设备的**网关和 DNS 都指向这台机器**(一般在 DHCP 里改一次就够了)。

设备的 DNS 查询会由内核接管(fake-ip、防泄漏),不再直接问上游。

## 设备页

网关模式下菜单里会多出一个「设备」页:自动发现在线设备(DHCP 租约 + 邻居表),每台可以单独设策略。

| 策略 | 行为 |
|---|---|
| 跟随规则 | 按当前模式与路由规则走(默认) |
| 强制代理 | 这台设备的流量一律走代理,不看规则 |
| 直连 | 一律直连 |
| 拒绝上网 | 直接断掉 |

按 **MAC** 记住,设备换了 IP 也跟着。命令行:

```bash
godusevpn devices                                  列出设备
godusevpn device <MAC> <follow|proxy|direct|reject> [名字]
```

## 网关模式下的 IPv6

**照样会停用网卡的 IPv6**。那正是「希望整个局域网都没有 v6 出口」的场景 —— 局域网里某台设备拿到公网 v6 地址,它的流量就绕过这台软路由直接出去了。

要保留局域网 IPv6,把设置里「连接时停用网卡 IPv6」关掉。详见 [[关于 IPv6]]。

## 注意

- 局域网网段可以在设置里手填(逗号分隔),留空自动识别。
- 面板默认监听 `0.0.0.0:9800`,软路由上通常就在局域网里开着,**记得设密码**。
- 梅林(Asuswrt-Merlin / Entware)走的是 TProxy 这条路,还在开发中,没有真机验证过。
