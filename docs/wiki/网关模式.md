# 网关模式(软路由)

本机模式只代理这台机器;网关模式还代理**经它转发的局域网设备**。适合 OpenWrt / iStoreOS 这类软路由,也适合 Debian / Ubuntu 上搭的双网口路由或单网口旁路由。

需要内核带 nftables —— OpenWrt 22.03 起的 fw4 都有,Debian 11 / Ubuntu 22.04 起也都有。

## 开

设置 → 网络 → 网络模式选「网关」,或者:

```bash
godusevpn settings netMode=gateway
```

然后把局域网设备的**网关和 DNS 都指向这台机器**(一般在 DHCP 里改一次就够了)。

设备的 DNS 查询会由内核接管(fake-ip、防泄漏),不再直接问上游。这台机器上有 DNS 服务时(OpenWrt 的 dnsmasq),设备的查询先到它,它再问上游时被内核接住;没有的话(Debian、Ubuntu 上搭的旁路由),发给这台机器 53 端口的查询直接交给内核。

### 旁路由(只有一张网卡)

主路由管上网和 DHCP,这台机器只负责代理。开网关模式后,把要代理的设备的网关和 DNS 改成这台机器的地址(在设备上改,或者在主路由的 DHCP 里改)。没改的设备不受影响。

只有一张网卡时,设备页不再把这张网卡上的邻居当成"上游"全部排除,只排除主路由自己。同网段里跟这台机器说过话的设备都会列出来,哪怕它的网关没指过来 —— 策略只对真的经过这台机器的流量起作用。

### IP 转发

普通 Linux 默认不转发。转发关着时设备的 TCP 还能用,UDP 全丢(网页能开,QUIC、语音、游戏都不通),所以连接时会自动打开 `net.ipv4.ip_forward`、断开时关回去;本来就开着的(OpenWrt 都是)不动。

用了 `ufw` 或别的防火墙把转发默认拒绝的,要自己放行局域网到隧道网卡(`godusevpn`)的转发。开着 IPv6 时 `net.ipv6.conf.all.forwarding` 不会自动开:它会让这台机器自己不再接受路由通告,要转发 IPv6 请自己决定。

## 设备页

网关模式下菜单里会多出一个「设备」页:自动发现在线设备(DHCP 租约 + 邻居表),每台可以单独设策略。容器、虚拟机和别的 VPN 网卡上的邻居不算设备。

| 策略 | 行为 |
|---|---|
| 跟随规则 | 按当前模式与路由规则走(默认) |
| 强制代理 | 这台设备的流量一律走代理,不看规则 |
| 直连 | 一律直连(全局模式下「防流量逃逸」开着时不生效,照样走隧道) |
| 拒绝上网 | 直接断掉 |

按 **MAC** 记住,也按 MAC 生效:

- 设备换了 IP,策略马上跟着,不用重启内核,别的设备的连接也不会断。
- 设备离线后它的 IP 分给别人,别人不受影响。
- 设备的每个地址都算,包括 IPv6。
- 手机的「随机 MAC / 私有地址」换了就算一台新设备。要固定策略,就在手机上给这个 Wi-Fi 关掉随机地址。
- 设备隔着另一台路由器(不是桥接的 AP)时,这边只看得到那台路由器的 MAC,策略只能整体设在那台路由器上。

这个页面不分配 IP。要给设备固定地址,在路由器的 DHCP 里按 MAC 设静态租约;策略本身已经不依赖地址了。

**隧道异常时**(「防流量逃逸」开着,内核崩溃、在重启或服务没起来):

| 策略 | 规则模式 | 全局模式 |
|---|---|---|
| 跟随规则 | 直连规则的 IP 段照常(默认局域网和国内 IP),其余拦下 | 只等隧道(局域网直通开着时局域网照常) |
| 强制代理 | 拦下 | 同上 |
| 直连 | 照常直连 | 同上(这时直连策略本来就不生效) |
| 拒绝上网 | 拦下 | 拦下 |

这时设备的直连不经内核,靠路由器自己转发:OpenWrt 本来就有 NAT;Debian / Ubuntu 上搭的要留着自己的 MASQUERADE。

DNS 同样按这张表:规则模式下照常能解析(路由器上的 dnsmasq 问它的上游;没有 DNS 服务的机器改问设置里的本地 DNS,要是公网 IPv4 地址,否则用 223.5.5.5;设备自己写死的 DNS 也放行);全局模式下解析不了,等隧道回来。

进程被杀或崩溃时,内核来不及清掉自己的转发规则,服务单元和下一次启动会清:systemd 上进程一退就清,OpenWrt 约一秒后重启时清,梅林最多等一分钟(看门狗每分钟看一次)。

命令行:

```bash
godusevpn devices                                  列出设备
godusevpn device <MAC> <follow|proxy|direct|reject> [名字]
```

## 网关模式下的 IPv6

**照样会停用网卡的 IPv6**。那正是「希望整个局域网都没有 v6 出口」的场景 —— 局域网里某台设备拿到公网 v6 地址,它的流量就绕过这台软路由直接出去了。

要保留局域网 IPv6,把设置里「连接时停用网卡 IPv6」关掉。详见 [[关于 IPv6]]。

## 注意

- 面板默认监听 `0.0.0.0:9800`,只给本机和局域网打开(从公网打不开,要开见「安装 Linux」),**记得设密码**。
- 梅林(Asuswrt-Merlin / Entware)走的是 TProxy 这条路,还在开发中,没有真机验证过。
