装完就生效的几件事

下面这些不是可选项,是默认行为。

全机接管,不靠系统代理

开 TUN 网卡把流量整个接进内核,不改系统代理设置,不挑应用。严格路由会拦掉绕过隧道的 DNS 与直连尝试。

默认没有 IPv6五层

DNS 只回 A、不发 v6 fake-ip、隧道里按协议族拒绝、v6 接进隧道再丢掉,最后连网卡的 IPv6 协议也停用——地址不存在,应用就读不到。断开按动手前的状态还原。

看得见的出口

首页显示这条线路真正的出口地址与城市——节点名写的是机房位置,真正的出口未必在那儿。换节点立刻重测。

规则组自己排

名称、出口、任意多条条件(域名 / 关键词 / 正则 / IP 段 / 端口 / 进程名 / geosite / geoip),自上而下匹配,可启停排序。内置那三条默认规则也能改。

订阅刷新有回退链

经当前节点刷新失败就改用自动选择组,再不行直连刷新。回退只作用于这一条请求,选中的节点和其它流量的路由都不动。

四端同一份代码

守护进程、页面、数据布局都是同一份。Linux 上多一个网关模式:局域网设备把网关指过来就走,每台可单独设策略。

支持的平台

安装细节见文档。

Windows

10 1809(17763)及以上 · x64 / ARM64

安装包带后台服务、托盘客户端与命令行,注册 godusevpn:// 供落地页一键导入。程序未签名,SmartScreen 提示时点"仍要运行"。

取安装包

macOS

13 Ventura 及以上 · Apple / Intel

curl 一行装,不用买开发者证书,也不用去系统设置里点允许。

curl -fsSL https://raw.githubusercontent.com/Maoyangui/godusevpn/master/deploy/macos-install.sh | sudo sh
安装说明

Linux

桌面 / 服务器 / 软路由

一个静态二进制,自带浏览器面板。软路由可开网关模式,局域网设备逐台设策略。

curl -fsSL https://raw.githubusercontent.com/Maoyangui/godusevpn/master/deploy/install.sh | sh
安装说明

Android

8.0 及以上 · 手机与电视

侧载 APK,VpnService 接管。电视上遥控器能走完全部操作,按应用直连在设置里选包名。
