m-ui 面板的客户端
四个平台,一套界面

填一条订阅链接就能用。内嵌 sing-box,开 TUN 接管全机流量,规则 / 全局 / 直连三种模式,默认把 IPv6 关掉。

它做了什么

不是又一个订阅转换器。下面这些是装完就生效的默认行为。

全机接管,不靠系统代理

开 TUN 网卡把流量整个接进内核,不改系统代理设置,不挑应用。严格路由会拦掉绕过隧道的 DNS 与直连尝试。

默认没有 IPv6

DNS 只回 A 记录、不发 v6 fake-ip、隧道里按协议族拒绝,再加一层:连接期间停用各网卡的 IPv6 协议,断开时按动手前的状态还原。网卡上没有公网 v6 地址,应用就读不到。

看得见的出口

首页显示这条线路真正的出口地址与城市——节点名写的是机房位置,真正的出口未必在那儿。换节点立刻重测。

规则组能自己排

名称、出口、任意多条匹配条件(域名 / 关键词 / 正则 / IP 段 / 端口 / 进程名 / geosite / geoip),自上而下匹配,可启停排序。内置的三条默认规则也能改。

订阅刷新有回退链

经当前节点刷新失败就改用自动选择组,再不行直连刷新。回退只作用于这一条请求,选中的节点和其它流量的路由都不动。

四端同一份代码

守护进程、页面、数据布局都是同一份。Linux 上还多一个网关模式:局域网设备把网关指过来就能走,每台设备可单独设策略。

支持的平台

Windows 10 1809+

x64 / ARM64。安装包带后台服务、托盘客户端与命令行,注册 godusevpn:// 供落地页一键导入。

macOS 13+

苹果芯片与英特尔各一个包。launchd 后台服务 + 启动台里的图形界面。

Linux

一条命令装好守护进程,浏览器打开内置面板。软路由(含 Merlin / Entware)可用网关模式。

Android 8+

VpnService 接管,手机与电视都能用,电视上遥控器可以走完全部操作。

GPL-3.0,与内嵌的 sing-box 一致。第三方素材的出处见仓库根的 NOTICE。
