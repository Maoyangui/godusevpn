佛跳墙 · 在 Mac 上安装

三步装好,不用敲命令。需要 macOS 13 或更高。这个文件夹是 v__VERSION____ARCHNAME__ · __ARCH__

1

双击「安装佛跳墙.command」

就在这个说明旁边。不要直接打开 godusevpn.app —— 它要先装好后台服务才能用。

先确认包没下错:苹果菜单 →「关于本机」,写着「芯片 Apple M…」用 arm64 包,写着「处理器 Intel…」用 amd64 包。下错了安装程序会提醒你。

2

第一次会被 macOS 拦下,放行一次

佛跳墙没有花钱买苹果的开发者证书,macOS 认不出是谁发布的,所以会拦。只拦这一次、只拦这一个文件,装好后的佛跳墙不会再被拦。

macOS 15 Sequoia 及更新 弹窗点 完成 → 打开「系统设置」→「隐私与安全性」→ 拉到下面的「安全性」,在"已阻止使用「安装佛跳墙.command」"旁边点 仍要打开 → 输入密码或用触控 ID → 再点 仍要打开。
macOS 13 Ventura / 14 Sonoma 按住 control 点「安装佛跳墙.command」(或右键)→ 打开 → 弹窗里再点 打开。
3

在弹出的「终端」里输入开机密码,按回车

输入密码时屏幕上不会出现任何字符,连星号都没有 —— 这是正常的,输完直接按回车。

看到「✅ 安装完成」,佛跳墙会自动打开,终端窗口可以关掉。以后在启动台或聚焦搜索(⌘ 空格)里找「佛跳墙」打开(「应用程序」文件夹里显示为 godusevpn),在订阅落地页点「一键导入」就能用。

需要管理员账户。升级以后在应用里「关于 → 检查更新」,不用再来这里。

会用终端?这样更省事

按 ⌘ 空格 搜「终端」打开,粘贴下面这行回车,输开机密码。这条路不会被 macOS 拦,也不用放行。

curl -fsSL https://raw.githubusercontent.com/Maoyangui/godusevpn/master/deploy/macos-install.sh | sudo sh

卸载

双击「卸载佛跳墙.command」,输入 y 确认、再输开机密码。会撤掉后台服务和「禁直连」的防火墙规则、恢复网络设置,再删掉程序;设置和订阅留在 /Library/Application Support/godusevpn。

遇到问题

  • 双击后提示没有权限 / 什么也没发生:换个解压方式可能丢了执行权限,用上面"会用终端"那一行装。
  • 提示芯片和本机不符:下载另一个包(苹果芯片 arm64,英特尔 amd64)。
  • 终端里出现 is not in the sudoers file:当前账户不是管理员,换管理员账户登录后再装。
  • 更多见 Wiki · 安装 macOS。

Three steps, no typing commands. Needs macOS 13 or later. This folder is v__VERSION____ARCHNAME_EN__ · __ARCH__

1

Double-click "安装佛跳墙.command" (Install)

It sits next to this guide. Don't open godusevpn.app directly — it needs the background service installed first.

Right package? Apple menu → About This Mac: "Chip Apple M…" needs arm64, "Processor Intel…" needs amd64. The installer tells you if it's the wrong one.

2

macOS blocks it the first time — allow it once

godusevpn isn't signed with a paid Apple developer certificate, so macOS can't tell who published it. You only allow this one file once; the installed app won't be blocked again.

macOS 15 Sequoia and later Click Done → System Settings → Privacy & Security → scroll to Security, next to "安装佛跳墙.command was blocked" click Open Anyway → enter your password or use Touch ID → Open Anyway again.
macOS 13 Ventura / 14 Sonoma Control-click (or right-click) "安装佛跳墙.command" → Open → Open in the dialog.
3

Type your Mac login password in Terminal, press Return

Nothing appears while you type — not even dots. That's normal; just press Return when done.

When you see "✅ 安装完成" (installed), godusevpn opens by itself and you can close Terminal. Later, find 佛跳墙 in Launchpad or Spotlight (it shows as godusevpn in the Applications folder) and tap "one-click import" on your subscription page.

Needs an administrator account. Future upgrades: About → Check for updates inside the app.

Comfortable with Terminal? One line instead

Press ⌘ Space, open Terminal, paste this line and enter your password. This path is never blocked by macOS.

curl -fsSL https://raw.githubusercontent.com/Maoyangui/godusevpn/master/deploy/macos-install.sh | sudo sh

Uninstall

Double-click "卸载佛跳墙.command" (Uninstall), type y, then your password. It removes the service and the kill-switch firewall rules, restores network settings and deletes the app; settings stay in /Library/Application Support/godusevpn.
